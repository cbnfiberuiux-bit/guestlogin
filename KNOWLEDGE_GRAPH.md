# Knowledge Graph — guestlogin (CBN Guest Check-in)

Design source: `CBN Guest Check-in.dc.html` (Claude Design prototype, localStorage) → rebuilt on Supabase.

```mermaid
graph LR
  idx[public/index.html<br/>shell: login · Data Tamu · Check-in] --> app[public/app.js]
  idx --> css[public/style.css<br/>design tokens]
  idx --> jsb[public/JsBarcode.all.min.js<br/>CODE128]
  app --> db[public/db.js<br/>supabase-js 2.45.4]
  db --> cfg[public/config.js<br/>generated by build.sh]
  cfg -->|SUPABASE_URL / *_KEY| vercel[Vercel env]
  app -->|signInWithPassword| auth[(Supabase Auth)]
  app -->|select/insert/update/delete| guests[(guests)]
  app -->|rpc check_in| fn[[check_in · security invoker]]
  fn --> guests
  app -->|select own row| admins[(admins)]
  guests -.RLS: jwt email in.-> admins
  app --> ticket[E-ticket modal + PNG canvas]
  ticket --> jsb
  app --> result[Full-screen VIP / Regular / Unknown + WebAudio]
  cam[BarcodeDetector camera / USB scanner / typing] --> app
  schema[supabase/schema.sql] --> guests & admins & fn
```

| Node | Owns | Depends on |
|---|---|---|
| `supabase/schema.sql` | `guests(code CBN-XXXXXXX, name, company, tier VIP/REGULAR, table_no, checked_in_at)`, `gen_guest_code()`, `admins(email)`, RLS, `check_in()`; drops old `get_guest()` | — (re-runnable, upgrades v1) |
| `public/app.js` | `EVENT`, `RESET_SEC`, `SOUND` constants; admin CRUD/filter/search/stats; ticket + PNG; check-in flow, log (in-memory, per device); camera; sound | `db.js`, `JsBarcode`, `check_in`, `guests`, `admins` |
| `public/index.html` | static markup for all views | `style.css`, `config.js`, `JsBarcode`, `app.js`, Google Fonts (Plus Jakarta Sans, JetBrains Mono, Material Symbols Rounded) |
| `public/style.css` | design tokens (`--blue #1D5BFF`, `--ink #0A1226`, gradients) + all component styles | — |
| `build.sh` → `public/config.js` | injects public Supabase URL + key at Vercel build | Vercel env `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` (or `*_ANON_KEY`, `NEXT_PUBLIC_*`) |
| `vercel.json` | static output `public/`, `/admin` → `/` redirect | `build.sh` |

Invariants
- Barcode encodes the bare code (`CBN-XXXXXXX`); ticket never shows tier — tier is revealed only on the scan screen.
- Check-in is staff-only (authenticated + in `admins`); first scan → `ok`, later → `again`, unknown → no row.
- Old v1 QR links (`/?c=code`) still check in: `checkIn()` extracts `c=` and codes were upper-cased.
- `?view=checkin` opens the Check-in tab directly.
- Camera scan needs `BarcodeDetector` (Chrome Android/Mac); iPhone Safari → USB scanner or typing.
